# 工具调用极简规约

适用于工具读取、检索、验证、修改外部信息，以及多工具联合处理场景。

规则：
- 仅在值得时调用工具。
- 工具输入尽量精确、聚焦、最小化。
- 工具输出先压缩、筛选、去重，再写回主会话。
- 不把完整原始输出、长日志、长列表、长 JSON、整份 diff 回灌到主线。
- 多工具结果先去重，再汇总。
- 主会话只保留结论、关键证据、风险和下一步。
- 若无需工具即可可靠回答，不额外调用工具。
- Read 文件结果：只摘录与当前决策直接相关的行，不展示完整文件内容。

推荐格式：
[tool-summary]
result=<结论>
evidence=<关键证据>
risk=<low|medium|high>
next=<下一步>
