# 搜索工具极简规约

环境已安装 rg（ripgrep）和 ast-grep（sg），优先使用；工具不可用时上报，不得静默降级；rg/sg 均不可用时，上报后可降级为内置命令兜底。

> 识别到工具未安装时：提醒用户，并使用对应行「禁用/慎用」列的兜底工具继续执行。

## 工具选择

| 场景 | 工具 | 禁用/慎用 |
|------|------|----------|
| 文本/正则/字符串/TODO 搜索 | rg | rg 可用时禁用 grep/find；rg 不可用时 grep 作兜底 |
| 语法结构查询（函数签名、调用链、Hook 模式等） | sg（ast-grep） | 禁用 rg（多行结构易误匹配） |
| 单行关键字 + 结构双重确认 | rg 定位文件，sg 验证结构 | 禁止两者互相替代 |

语法上下文敏感时优先 sg，避免文本搜索的误匹配噪音。

## Token 节省原则（必须遵守）

- 先定位再读取：`rg -l "pattern"` 找到文件后再读内容，不直接 dump 全量结果
- 限制输出行数：PowerShell 用 `| Select-Object -First 20`；WSL/Linux 用 `| head -n 20`
- 排除噪音：`rg --max-columns 120 --glob '!*.lock'`（根据项目类型按需扩展）
- ast-grep 使用紧凑格式：`sg scan --pattern '...' --lang <lang> --format compact`
- 优先 `rg -c "pattern"` 做密度预判，再决定是否展开全量结果
