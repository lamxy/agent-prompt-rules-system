
## 审计机制

### 触发条件（满足任一）
- 单次任务完成，输出前
- 多轮任务每 5 轮
- 用户显式要求审计

### 执行方式
通过子代理执行。子代理加载审计清单：
- `cat .claude/rules/audit/rule-audit-checklist-short.md`

主代理构造审计输入摘要，连同清单一起传给子代理。

### 审计输入摘要（主代理构造，传给子代理）
- 已加载的规约文件列表
- 已加载的模板列表
- 任务类型
- 是否调用了工具（及数量）
- 是否使用了子代理/代理团队
- 是否为周期性任务
- 最近一轮输出的 token 量级（短/中/长）

### 审计输出格式（子代理返回）
```
审计结果: 通过 | 有问题
问题项: [未通过的检查项编号及一句话说明]
建议: [最关键的一条改进]
```

### 约束
- 审计子代理只读，不修改任何输出
- 审计结果不超过 5 行
- 若全部通过，只返回"审计结果: 通过"
- 审计本身不触发额外规约加载
