# 推荐仓库与教程文档

本目录用于收集与 Agent 编码工作流相关的优秀仓库，并为每个仓库提供可复现的详细使用教程，帮助使用者快速理解、上手和落地。

## 目录分组

- `official/`：官方仓库与官方工具链
- `github/`：开源社区仓库（已验证可用）
- `custom/`：团队或个人自定义推荐仓库

## 推荐范围

类型包括但不限于：

- 插件
- skills
- MCP 工具
- agents
- 工程效率与协作工具

## 教程文档要求（必须）

每个推荐仓库都需要配套一篇详细教程文档，建议命名为：

- `<repo-name>-详细使用教程.md`

教程至少包含以下内容：

1. 仓库定位与核心能力
2. 适用场景与不适用边界
3. 安装与环境准备步骤
4. 最小可运行示例（可直接复现）
5. 常见问题与排错建议
6. 与 Agent 工作流结合方式（可选但推荐）

## 维护建议

- 优先更新已有教程，避免重复创建同类文档
- 文档以实操步骤为主，减少纯概念描述
- 对失效链接或过时步骤进行定期清理
